# LiveVoiceBridge

LiveVoiceBridge は、YouTube Live などの配信チャット（コメント）をリアルタイムに取得し、VOICEVOX・COEIROINK・棒読みちゃん・Qwen3-TTSを使って読み上げるためのデスクトップアプリケーションです。
視聴者からのコメント内容に応じて読み上げ音声の速度・音量・キャラクターを動的に変更したり、効果音（SE）を鳴らしたりするインタラクティブな機能を備えています。

---

## 主な特徴

- 🎙️ **多彩な音声合成（TTS）エンジンへの対応**
  - VOICEVOX、COEIROINK、棒読みちゃん、Qwen3-TTSに対応。
- 💬 **コメント内特殊コマンドによる動的制御**
  - コメント中に特定のテキストを含めることで、速度・音量・音程・話者の変更、効果音の再生、さらにはユーザー辞書の教育・忘却が可能です。
- 🎛️ **音声エフェクト処理**
  - 音声波形を直接加工し、エコー、山びこ（3回ディレイ）、パンニング（左・右・両耳）効果を適用できます。
- 📺 **ピクチャーインピクチャー（PiP）コメント表示**
  - コメント一覧部分を半透明かつ最前面表示が可能な独立ウィンドウとして分離（ポップアウト）できます。

---

## 技術スタック

- **GUI フレームワーク**: PySide6 (Qt for Python)
- **ネイティブコア**: Rust / PyO3（メトリクス収集、コメント解析、辞書最長一致、音声DSP）
- **音声再生**: Rust / rodio（Windows・Linux）。外部再生コマンドや一時WAVは使用しません。
- **通信**: gRPC (YouTube 配信チャットのストリーミング取得)

## 対応音声合成（TTS）エンジン

設定画面または `config.json` にて、以下のいずれかのエンジンを選択できます。

1. **VOICEVOX / COEIROINK**
   - 外部で起動しているローカルサーバー（デフォルト: VOICEVOX `http://127.0.0.1:50021` / COEIROINK `http://127.0.0.1:50032`）に HTTP リクエストを送信して音声を生成します。
   - アプリ側から実行ファイル（`.exe`）のパスを指定して自動起動させることも可能です。
2. **棒読みちゃん**
   - Socket 通信（デフォルト: `127.0.0.1:50001`）を介して棒読みちゃん本体に音声生成と再生を指示します。
3. **Qwen3-TTS 0.6B CustomVoice**
   - 専用のOpenVINOサービスに接続します（`http://127.0.0.1:50040`）。日本語・標準話者 `ono_anna` を使用し、GPUでモデルを常駐させます。
   - 文単位で合成したWAVを既存の再生キューへ渡します。音量・話者・最大文字数を設定できます。
   - 導入・起動手順と制限は [Qwen3-TTSの導入](docs/qwen3.md) を参照してください。

## コメント内特殊コマンド

視聴者が配信チャットで以下の書式を使ってコメントすると、読み上げ動作やシステム辞書を動的にコントロールできます。

### 1. ユーザー辞書登録（教育・忘却）
- **教育**: `教育(単語=よみがな)`
  - 例: `教育(LiveVoiceBridge=ライブボイスブリッジ)`
  - 効果: 辞書の「配信コメント」グループに対象の単語が登録され、以降その単語は指定されたよみがなで読み上げられます。
- **忘却**: `忘却(単語)`
  - 例: `忘却(LiveVoiceBridge)`
  - 効果: 「配信コメント」グループから対象の単語を削除します。

### 2. 効果音再生（SE）
- **SE再生**: `再生(ファイル名)` または `音(ファイル名)` または `sound(ファイル名)`
  - 例: `再生(warning.wav)` / `sound(cheer.wav)`
  - 効果: 配置先の `data/sounds/` フォルダ内から対象のオーディオファイルを検索し、コメント読み上げと同時に再生します。
  - *※セキュリティのため、パス指定は無視されファイル名部分のみが抽出されます。*

### 3. 音声パラメータ調整
コメントの途中で以下のコマンドを挿入すると、それ以降のテキストの読み上げ属性が変更されます。（1つのコメント内で複数回変更可能です）

| コメント記述 | 対象パラメータ | 設定値と変換仕様 |
| :--- | :--- | :--- |
| `速度(数値)` | 話速（スピード） | 指定値 / 100 倍（例: `速度(120)` は 1.2 倍速） |
| `音程(数値)` | 音高（ピッチ） | `(指定値 - 100) / 100 * 0.15` の式でピッチ差分を算出 |
| `音量(数値)` | 音量（ボリューム） | 指定値 / 100 倍（例: `音量(80)` は 80% の音量） |
| `声(数値)` | 話者（キャラクター） | TTS エンジン側の Speaker ID を指定値に変更 |
| `エコー(数値)` | エコー効果 | エコーの減衰率を設定（数値が大きいほど響きが強くなります） |
| `やまびこ(数値)` | 山びこ効果 | 山びこ（3回の減衰ディレイ）の減衰率を設定 |

### 4. パンニング（定位）
コメントの文頭や途中でパンニングコマンドを挟むことで、左右の定位を振ることができます。

- `左)` または `左）`: 音声を左チャンネルのみから再生します。
- `右)` または `右）`: 音声を右チャンネルのみから再生します。
- `両)` または `両）`: 音声を両チャンネル（ステレオ）に戻します。

## 設定ファイル (`config.json`)

配置先の `data/` に初回生成される `config.json` で詳細な設定を行えます。

設定はバージョン付きの階層構造です。主要セクションは次のとおりです。

- `schema_version`: 設定スキーマのバージョン。
- `streaming`: APIキー、接続先、履歴・有料イベントの読み上げ設定。
- `speech`: 選択中のエンジン、全エンジンの設定、読み上げブロック。
- `presentation`: コメント表示、PiP、配信メトリクス表示。
- `dictionary`: 選択中の辞書グループ。
- `application`: 更新確認や入力方式などのアプリ設定。
- `resources`: コメント・ログの保持数、音声・アバターの保持容量。

正式スキーマのみを受け付けます。未対応のエンジンや不正な設定はエラーとして通知します。

## コード構成

- `core`: session・chat・speech・dictionary・settings・telemetryの型・契約・処理。
- `integrations`: YouTube、TTS、保存、音声、Rustの具象実装。
- `desktop`: Qt画面、Presenter、表示モデル、Designerフォーム。
- `host`: 起動・データ配置・依存の組み立て。
- `native`: Rust / PyO3の解析・辞書照合・DSP・メトリクス。
- `services/qwen3`: 独立した環境の推論サービス。
- `tools`・`packaging`: 開発コマンド・配布定義。

Python本体は `src/livevoicebridge` 配下にあります。依存方向と循環参照はテストで検査します。
第二弾の構造・検証範囲は [OS処理とリソース管理](docs/native-resource-refactor.md) を参照してください。

## データと起動

配布フォルダを任意の場所へ展開し、`LiveVoiceBridge.exe` を起動します。同梱の `_internal/` も一緒に配置してください。
設定・辞書・効果音はEXEと同じ配置先の `data/` に保存します。音声は容量制限付きのRust所有PCMバッファで扱い、一時音声ファイルは生成しません。配置先には書き込み権限が必要です。
ソースからの開発起動は `python -m livevoicebridge` です。この場合はリポジトリ直下を配置先として扱います。

```text
LiveVoiceBridge/
├── LiveVoiceBridge.exe
├── _internal/
└── data/
    ├── config.json
    ├── dictionary.json
    └── sounds/
```

配布フォルダ全体で移動・削除できます。AppDataやOSの一時フォルダをアプリの保存先には使用しません。

- `config.json`: schema_version 3。エンジン固有の設定を保存します。
- `dictionary.json`: 全辞書グループの原子的なスナップショット。JSON・CSV・TXTのインポートに対応します。
- `sounds/`: 効果音ファイル。

旧import、main.py、旧設定、旧辞書配置への互換処理はありません。旧データは自動で移動・削除しません。
