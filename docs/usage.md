# LiveVoiceBridge 使用方法・マニュアル

本ドキュメントでは、LiveVoiceBridge のセットアップ方法から基本的な起動・操作手順、各種機能の詳しい使い方について解説します。

---

## 1. セットアップ（事前準備）

### ビルド済みアプリの配置

配布フォルダを、書き込み可能な任意の場所へ展開してください。EXEと `_internal/` は一緒に配置します。
アプリ本体を使うためにPython・Rust・venvを用意する必要はありません。
ソースから開発する場合は[開発ガイド](development.md)を参照してください。

### 音声合成（TTS）エンジンの準備

VOICEVOX、COEIROINK、棒読みちゃん、Qwen3-TTSのいずれかを別途用意してください。Qwen3-TTSは[専用サービスの導入手順](qwen3.md)に従って準備します。
接続先と自動起動用の実行ファイルパスは、アプリの設定画面で指定します。

---

## 2. アプリケーションの起動

Windowsでは `LiveVoiceBridge.exe`、Linuxでは配布された `LiveVoiceBridge` を起動します。
設定・辞書・効果音は配置先内の `data/` に保存します。音声の一時ファイルは生成しません。
設定はschema_version 2、辞書はSQLiteの `dictionary.db` です。
旧 `dictionary.json` は自動変換しません。辞書タブの「インポート」で取り込めます。元ファイルは変更しません。
schema_version 1の設定は読み込み時に一度だけ2へ変換し、同じファイルへ保存します。
元の内容は隣の `config.json.schema1.bak` に保存します。変換・バックアップ・保存に失敗した場合は元の設定を維持します。
既存バックアップの内容が元の設定と異なる場合は、上書きせず変換を中止します。
配信・画面・辞書・読み上げ設定を引き継ぎ、新しい項目は既定値で補います。
廃止されたSupertonic設定は除去し、選択中だった場合はVOICEVOXへ切り替えます。
Qwen3の旧接続URLは引き継がず、モデル未設定の場合は設定画面からセットアップしてください。
バージョン指定のない旧形式や、1・2以外のスキーマは変換しません。
ソース起動ではリポジトリ直下が配置先となり、開発環境のRust拡張も最新APIへの再ビルドが必要です。

---

## 3. 初期設定（APIキーとTTSの設定）

起動後、まずYouTube接続と読み上げに必要な初期設定を行います。

1. **設定ダイアログを開く**:
   - メインウィンドウ右上の「⚙️（設定ボタン）」をクリックするか、メニューの「ツール」→「設定」を選択します。
2. **YouTube Data API Key の入力**:
   - 「YouTube設定」の項目にある API Key 欄に、取得した YouTube Data API v3 のキーを入力します。
   - 入力欄の右側にある外部リンクボタンをクリックすると、APIキーの取得先である [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) にブラウザでアクセスできます。
   - *(※取得手順：プロジェクトの作成または選択 ➜ 「YouTube Data API v3」を検索して有効化 ➜ 「認証情報」から「API キー」を作成)*
   - *※ローカルデバッグモードのみを使用する場合は、空欄でも構いません。*
3. **TTS（音声合成）エンジンの選択**:
   - 使用したい TTS エンジン（VOICEVOX、COEIROINK、棒読みちゃん、QWEN3）を選択します。
   - **VOICEVOX / COEIROINK / 棒読みちゃん**:
     - 既に外部で起動している場合はその URL/ポート を指定します。
     - 自動起動させたい場合は、それぞれの「実行ファイルのパス」を指定しておくと、最初の読み上げ準備時にバックグラウンドで起動されます。
   - **QWEN3**:
     - 「モデルの準備」で「モデルをダウンロードする」または「手元のモデルを使う」を選びます。Pythonや接続URLの指定は不要です。
     - 準備したモデルはその場で登録・保存されます。通常の設定ダイアログのキャンセルでは、この登録や取得済みファイルは取り消しません。
     - Qwen選択時はバックグラウンドでロードします。ロード中もコメント取得と画面操作を続けられます。
4. **設定の保存**:
   - 「OK」ボタンを押して設定を保存します（編集はドラフトとして保持し、キャンセル時は保存しません）。

## 4. 基本的な操作手順

### YouTube 配信コメントの読み上げ開始
1. メインウィンドウの「YouTube URL または Video ID」入力欄に、接続したいライブ配信の URL または動画IDを入力します。
2. 「開始」ボタンをクリックします。
3. 接続に成功すると、ステータスが「配信接続中」に変わり、配信チャットに投稿されたコメントがリアルタイムに取得され、自動で読み上げられます。

### コメントの読み上げ停止
- 読み上げを終了する場合は、「停止」ボタンをクリックします。接続が切断され、ステータスが「停止中」になります。
- 未処理のコメントと再生待ち音声は破棄します。実行中の音声生成・再生は完了してから終了します。

### 音声生成と再生の流れ
- 音声生成は1件ずつ行い、生成が完了してから次の文を生成します。
- 再生は別の処理で受信順に行います。再生中でも次の文・次のコメントの生成を進めます。
- 読み上げ文章はコメント内コマンドと「。」で分割し、同じ文章でも毎回生成します。
- 棒読みちゃんは発声命令の送信処理が終わってから次を送信します。本体の発声完了は待ちません。

### テスト送信モード（デバッグ）
YouTube Liveに接続せず、ローカル環境だけで読み上げや辞書のテストを行いたい場合に使用します。
1. 「テスト送信」ボタンを押します。配信URLやAPIキーは不要です。
2. ダイアログへテキストを入力します。配信コメントと同じ計画・合成・再生処理を使います。
3. コメントコマンドも利用できます。終了するときは「停止」を押します。

### ログとコメントのクリア
- 画面に表示されているコメント一覧および動作ログテキストをリセットしたい場合は、「ログクリア」ボタンをクリックします。

## 5. 各種機能の詳しい使い方

### 📎 ピクチャーインピクチャー（PiP）コメントウィンドウ
コメント表示部分をメインウィンドウから切り離し、デスクトップ上の好きな位置に最前面で常時表示（半透明表示も可能）させることができます。

- **切り替え方法**:
  - メインウィンドウ上部にある PiP ボタン（テレビや画面のアイコン）をクリックすると、コメントリストが独立した `CommentWindow` に移動します。もう一度クリックするとメインウィンドウのタブに戻ります。
- **ウィンドウの調整**:
  - 分離されたコメントウィンドウは、端をドラッグすることで自由にサイズを変更できます。また、位置も自動保存されます。
  - 設定ダイアログの「コメントウィンドウ不透明度」スライダーを調整することで、ウィンドウの背景を半透明にし、配信画面等に重ねやすくなります。

### 📖 ユーザー辞書と単語インポート
特定の単語の誤読を防ぐための辞書機能です。
表はスクロール位置に応じて256件ずつ取得し、取得済み行は最大2,048件だけ保持します。
編集・インポート・グループ操作はOKでまとめて反映します。キャンセルでは読み上げ用辞書を変更しません。

- **インポート手順**:
  1. 設定ダイアログの「辞書」タブを開きます。
  2. 「インポート」ボタンをクリックし、手持ちの辞書ファイルを選択します。
     - **対応フォーマット**:
       - **JSON**: `[{"word": "単語", "reading": "よみがな"}]`、`{"単語": "よみがな"}`、または旧 `dictionary.json` のグループ別形式。グループ別形式はグループ名も取り込みます。
       - **CSV**: カンマ区切りのテキスト（1列目: よみがな、2列目: 単語、3列目: 品詞、4列目: メモ）
       - **TXT**: タブ区切りのテキスト（辞書ツール形式）
  3. 取り込み結果を確認し、OKで読み上げ用辞書に反映します。インポート途中で失敗した場合は、そのインポート分を取り消します。
- **配信中の教育**:
  - 視聴者がチャット欄で `教育(単語=よみがな)` とコメントすることで、自動的にユーザー辞書の「配信コメント」グループに登録されます。
  - 設定画面で編集中でも、別の単語への教育は保存時に維持します。同じ単語や削除対象グループが変更された場合は上書きせずエラーにします。キャンセルして開き直し、最新の辞書を確認してください。

### 🎵 音声エフェクトと効果音（SE）の利用
- **効果音（SE）の準備**:
  - EXEの配置先の `data/sounds/` ディレクトリ（存在しない場合は初回起動時に自動生成されます）に、再生したい音源ファイル（`.wav` など）を配置します。
  - 視聴者がコメント内で `再生(ファイル名)`（例: `再生(applause.wav)`）と打つことで、読み上げと同時に効果音が再生されます。
- **エコー・山びこ**:
  - `エコー(50)` または `やまびこ(50)` コマンドをチャットに含めることで、自製の波形ディレイ効果が付与されます。
  - やまびこは3回リピート（減衰あり）、エコーは1回のリピート効果になります。
- **定位（パンニング）**:
  - `左)` や `右)` コマンドで、音声の出力チャンネルを左側のみ、右側のみに瞬時に切り替えることができます。`両)` で左右均等に戻ります。

## リソース上限

設定の「リソース」タブで、スライダーとスピンボックスを使って変更します。OKで保存・適用し、キャンセルでは変更しません。

| 項目 | 初期値 | 範囲 |
| --- | --- | --- |
| コメント保持件数 | 1000件 | 100～10000件、100件刻み |
| ログ保持行数 | 2000行 | 100～20000行、100行刻み |
| 合成済み音声の保持容量 | 32MiB | 4～256MiB、4MiB刻み |
| アバターキャッシュ容量 | 8MiB | 1～64MiB、1MiB刻み |

上限を下げると古いコメント・ログ・画像から解放します。
音声は受け付け済みの再生待ちを捨てず、新規合成を待機して自然に減らします。
この変更だけでは読み上げセッションを再起動しません。1音声の最大容量は保持容量の半分、最大16MiBです。

メトリクスの「計測中」「取得不可」「未対応」は、正常な0%と区別します。
NPUの使用率は実測できるまで表示しません。
