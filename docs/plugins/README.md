# TTSプラグイン

[ドキュメント一覧](../README.md)

## 内蔵と外部

VOICEVOX・COEIROINK・棒読みちゃん・Qwen3は本体パッケージ内の内蔵プラグインです。
本体と一緒に配布・更新され、アプリ直下の `plugins/` には配置されません。
棒読みちゃんの内蔵プラグインはWindows対象です。

外部プラグインは、アプリ直下に次のように配置します。開発時のアプリ直下はリポジトリ直下です。

```text
LiveVoiceBridge/
  plugins/
    example_http/
      manifest.json
      entry.py
  data/
    config.json
    plugins/
      example_http/
```

配置でインストール、該当プラグインフォルダーの削除でアンインストールします。
更新はアプリを終了してフォルダーの内容を入れ替えます。
配置・削除・有効無効は再起動で反映されます。

## 有効化と設定

1. 外部プラグインを配置してアプリを起動します。新規の外部プラグインは無効です。
2. 設定の「プラグイン」で名前・内蔵／外部・版・形式・状態・エラーを確認し、有効にして保存します。
3. アプリを再起動し、「音声合成」でTTSを選び、接続先などを設定します。
4. 話者一覧の取得または話者IDの直接入力を行い、保存します。

内蔵プラグインも無効化できます。有効無効の変更は設定を保存して再起動すると適用されます。
選択したTTSが利用できない場合、読み上げ開始時に設定の見直しを案内します。
別のTTSへの自動切り替えは行いません。

## 設定とデータ

TTS設定と有効状態は `data/config.json`、プラグイン専用の保存先は `data/plugins/<ID>/` です。
Qwenの既存の環境・モデルは引き続き `data/qwen/` で管理します。
外部プラグインのフォルダーを削除しても、設定・保存データは保持されます。
同じIDで再導入すると、以前の設定と有効状態を引き継ぎます。
完全に消去したい場合は、アプリを終了して関連する保存データも手動で削除してください。

既存の設定スキーマ1・2はスキーマ3へ自動変換します。
書き換え前の元データは `config.json.schema1.bak` または `config.json.schema2.bak` に保存します。
異なる内容の同名バックアップがある場合は、上書きせず変換を中止します。

## エラーと実行環境

ID重複、未対応OS/API版、不正なマニフェスト、登録失敗はプラグイン一覧に表示します。
内蔵IDと衝突した外部プラグインは読み込まれません。外部同士の同じIDは全件エラーです。

Python形式は本体プロセス内で実行され、本体環境にある依存パッケージを利用します。
必要な追加依存を本体へ自動インストールする機能はありません。
外部実行形式は専用プロセスで実行され、独自の実行環境を同梱できます。
いずれも信頼できる配布元から入手してください。プロセス分離は権限の隔離ではありません。
