## 現行の対応範囲

Windows・Linuxのデスクトップアプリです。正式配布はx64向けです。
YouTube Liveのチャットを1配信ずつ取得し、
VOICEVOX・COEIROINK・棒読みちゃん・Qwen3-TTSのうち1エンジンで読み上げます。
コメント表示、音声制御、SE、辞書、PiP、監視表示を備えます。
管理データはアプリ配置先内に保存します。更新確認は配布ページを案内します。

内蔵TTSと外部TTSは共通のプラグイン契約を使用します。
内蔵プラグインは本体パッケージ内、外部プラグインはアプリ直下のpluginsに配置します。
