# Qwen3-TTS 0.6B CustomVoice

Qwenのモデルと専用実行環境はアプリが管理します。操作にブラウザやコマンド入力は不要です。
対象はWindows・Linuxのx86_64環境です。専用Pythonは通常版CPython 3.14.9を自動配置し、本体や他用途のPython環境は変更しません。

## 初回の準備

設定でQWEN3を選び、「モデルの準備」を開きます。

- **モデルをダウンロードする**: 固定リビジョンのQwen3-TTS 0.6B CustomVoiceを取得します。
- **手元のモデルを使う**: 別の用途で取得したモデル全体のフォルダーを選びます。Hugging Faceのsnapshotフォルダーも指定できます。

通常形式のモデルは、アプリ管理領域にコピーしてOpenVINO形式へ変換します。
対応する変換済みモデルは参照して使用します。元モデルにはコンパイルキャッシュを含めて書き込みません。
Base、VoiceDesign、1.7Bは今回の対象外です。種類や必要ファイルが不正な場合は理由を表示します。

実行デバイスをGPUまたはCPUから選び、「準備を開始」を押します。GPUが既定です。
GPUが使用できなくてもCPUへ自動切り替えは行いません。

準備画面には段階、取得可能な進捗、詳細ログ、中止、再試行を表示します。
環境・モデルの取得にはネット接続が必要です。通常形式のモデルの変換には取得元モデルのPythonコードを使用します。
準備したモデルの登録はその場で保存します。親の設定画面をキャンセルしても、登録・取得済みファイルは取り消しません。

## ロードと読み上げ

使用エンジンがQwenなら、アプリ起動時、Qwenへの切り替え適用時、モデル準備完了時にバックグラウンドでロードします。
モデル読み込みとウォームアップが完了するまで「準備中」と表示します。
アプリ起動、画面操作、配信への接続、コメント取得はロードを待ちません。

ロード中の読み上げ対象は既存のキュー上限内で保持し、準備完了後に順番に読み上げます。
配信停止時は待機分を破棄しますが、モデルは維持します。
話者・音量・最大文字数の変更でもロード状態を維持します。
別エンジンへ切り替えたときとアプリ終了時に解放し、モデル・デバイスの変更時は読み込み直します。

読み込み失敗時は待機読み上げを破棄し、コメント取得は継続します。
設定画面の「再試行・再起動」と「詳細ログ」から状況を確認できます。
サービスはアプリ全体で1つ所有し、話者一覧の取得では終了しません。
接続先は自動決定するローカルHTTPです。アプリ専用の認証を使い、別用途のサービスには接続しません。
初回準備後の音声生成はオフラインで動作します。

## 対応範囲

- 日本語、既定話者は `ono_anna`。9人の話者から選択できます。
- 文単位のWAV生成です。音声ストリーミングは今回追加しません。
- 音量は0〜2倍。速度・音程・抑揚・間隔・自然文による話し方の指定には対応しません。
- 辞書・絵文字変換・文分割・再生中の後続合成・アプリ側の音声エフェクトを使用します。
- 同時合成は1件、1リクエストは2000文字までです。最大文字数の既定値は50です。

## 保存先と固定依存

専用環境・取得データ・変換モデル・キャッシュ・一時ファイル・ログは、配置先の `data/qwen/` に保存します。
手元のモデル自体は配置先外も参照可能です。元モデルや外部Python環境は変更しません。
設定は `data/config.json` のschema_version 2です。schema_version 1は読み込み時に一度だけ2へ変換します。
変換前の内容は `data/config.json.schema1.bak` に保存します。旧手動サービス接続URLは引き継がないため、
モデル未設定の場合は設定画面からQwen3をセットアップしてください。

通常版CPython、推論・変換ライブラリの取得URLとSHA-256をWindows・Linux別に固定しています。
モデルのリビジョンは `85e237c12c027371202489a0ec509ded67b5e4b5` です。
OpenVINO一式は2026年10月22日のnightly版、Optimum Intelも固定コミットを使用します。
`qwen-tts 0.1.1` の要求に合わせてTransformers 4.57.3を維持します。
NNCFの `numpy<2.5` とTorchの `setuptools<82` に合わせ、専用環境はNumPy 2.4.6・setuptools 81.0.0を維持します。
本体の開発・配布用venvとは依存を分離しており、本体側の更新を専用環境へ適用しません。
通常版OpenVINOへ自動置換しません。配布物にはサービスの導入用パッケージを同梱します。

## 検証状況

WindowsのPython 3.14.2で、実行用・変換用依存一式のpip dry-runによる依存解決を確認しています。
専用Python 3.14.9での実インストール、モデル変換、音声生成、Linuxの実動作は別途検証が必要です。
実装時は型チェックと静的検査のみ行い、アプリ起動・配布ビルド・音声再生・テスト実行・負荷計測は行いません。

旧構成の2026年10月23日の実機測定では、Core Ultra 7 255H / Arc 140T / RAM 16GBで、
短い文の合成・受信に約19〜22秒かかっています。今回の導入・起動管理の改善で合成速度が向上したとは扱いません。
