# Qwen3-TTS

[仕様書一覧](../README.md)

## 対応モデルと準備

対応するモデルは `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` です。
Base・VoiceDesign・1.7Bは対応しません。
設定画面の音声エンジンでQWEN3を選び、「モデルの準備」を開きます。

1. 「モデルをダウンロードする」または「手元のモデルを使う」を選びます。
2. 手元のモデルの場合は、モデル全体のフォルダーを指定します。Hugging Faceのsnapshotも指定できます。
3. 実行デバイスをGPUまたはCPUから選択します。既定はGPUです。
4. 「準備を開始」を押し、段階・進捗・詳細ログを確認します。

環境・モデルの初回取得にはネット接続が必要です。
通常形式のモデルは管理領域へコピーし、OpenVINOのFP16形式へ変換します。
変換には取得元モデルのPythonコードを使用します。
モデル形式と必要ファイルを検証し、不足や非対応の場合は理由を表示します。

すべての必要ファイルが揃うOpenVINO形式は元フォルダーを参照します。
OpenVINOモデルでテキストトークナイザーだけが不足する場合は、管理領域へコピーして生成します。
元のモデルへコンパイルキャッシュなどを書き込む処理はありません。
参照型モデルを外部で移動・削除した場合は、再度準備してください。

準備中は中止でき、失敗・中止後は再試行できます。
完了したモデルのパスとデバイスは通常の設定OKとは独立して保存します。
親の設定画面をキャンセルしても、この登録や取得ファイルは取り消しません。
Qwenを使用エンジンにする変更自体は、設定画面のOKで適用します。

## ロードと解放

Qwenを使用する設定ならアプリ起動時と設定適用時にバックグラウンドでロードします。
モデル・デバイスが変わると読み直し、話者・音量・最大文字数だけの変更ではロード状態を維持します。
モデルロード後にウォームアップの短い合成を行い、その完了後に準備完了になります。
ロード処理は画面操作とYouTube接続を待たせません。

| 状況 | 読み上げ・モデルの扱い |
| --- | --- |
| 通常ロード中 | 上限内で計画を保持し、準備完了後に処理 |
| モデル未設定・ロード失敗 | 待機を終了し、計画を破棄。コメント取得は継続 |
| 配信の停止 | 待機計画を破棄。モデルは維持 |
| 別エンジンへの切り替え | Qwenサービスを解放 |
| モデル・デバイスの変更、明示的再起動 | 既存の読み上げを取り消してサービスを作り直す |
| アプリ終了 | 専用サービスと準備処理を終了 |

「再試行・再起動」でやり直せます。「詳細ログ」で状態を確認してください。
モデル準備処理中は既存のサービスを停止し、既存の読み上げ計画も取り消します。
GPUが使えない場合にCPUへ自動切り替えはしません。

## 音声設定

日本語固定で、話者IDは次の対応です。

| ID | 話者 |
| --- | --- |
| 0 | ono_anna（既定） |
| 1 | vivian |
| 2 | serena |
| 3 | uncle_fu |
| 4 | dylan |
| 5 | eric |
| 6 | ryan |
| 7 | aiden |
| 8 | sohee |

音量は0～2、最大文字数の既定値は50です。
1合成要求は最終テキストで1～2,000文字までです。
本文の切り詰めなしを選んでも、このサービス上限は変わりません。

文単位でWAVを作り、本アプリの音声キューで再生します。
速度・音程・抑揚・間長・自然文による話し方の指定には対応しません。
辞書、絵文字変換、後続発話の先行合成、エコー・やまびこ・定位は共通経路を使用します。
音声を少しずつ受信して再生するストリーミング方式ではありません。

## 専用環境と保存先

Windows・Linuxのx86_64向けに、専用の通常版CPython 3.14.9をアプリが配置します。
本体のPythonや別用途のPython環境は変更しません。
環境・ダウンロード・変換済みモデル・キャッシュ・一時ファイル・ログは
配置先内の `data/qwen/` に保存します。
手元のモデルは配置先の外も参照できます。

専用サービスはアプリ全体で1つです。接続先ポートは自動決定し、専用認証を使います。
話者一覧の取得でサービスを終了することはありません。
準備が完了した環境とモデルによる音声生成はオフラインで行います。
新規取得が必要な場合はネット接続が必要です。

依存の固定値とサービス契約は[内部構造](../source/architecture.md)に記載しています。
モデル変換・実際の合成速度・各デバイスの動作は環境に依存し、この仕様書は性能値を保証しません。
