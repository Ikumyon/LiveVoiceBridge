# 読み替え辞書

[仕様書一覧](../README.md)

## 保存と照合

辞書は `data/dictionary.db` のSQLiteに保存し、Rust/PyO3が所有します。
初期グループは「デフォルト」です。各行はID・版・単語・読み・品詞・コメントを持ちます。

全グループの登録語が読み上げの照合対象です。
設定の `dictionary.active_group` は編集画面で選択するグループ名で、適用グループの絞り込みではありません。
同じ単語が複数ある場合は、グループIDの大きい登録、さらに行IDの大きい登録を優先します。
グループ名の順番では優先度は変わりません。

文字列の左から最長一致で置換します。大文字小文字や表記の自動正規化はしません。
置換した読みを再度辞書で置換することはありません。
各発話の合成直前に不変スナップショットを取得するため、同じ発話中に辞書の版は変わりません。
確定した変更は後続発話から反映します。すでに合成した音声には反映しません。

品詞・コメントは保存用の情報です。本アプリの照合は単語と読みを使い、
外部TTSエンジンのユーザー辞書へ同期するものではありません。

## 編集画面

グループの追加・名前変更・削除、単語行の追加・変更・削除、ファイルのインポートに対応します。
設定画面を開くとDB内に編集ドラフトを作り、OKで差分を確定し、キャンセルで破棄します。
Python側で全単語の一覧を作らず、256件単位で取得し、最大8ブロック・2,048件をキャッシュします。

読みが空で単語がある行は確定できません。新規の空単語行は確定時に取り除きます。
編集中に配信コメントの教育・忘却が行われても、無関係な行の変更は保持します。
同じ行や変更対象のグループが競合した場合は保存を拒否します。
キャンセルして画面を開き直し、最新状態で再編集してください。

同じDBを複数のアプリプロセスで同時に編集することは想定していません。
DBは排他ロックを使用し、別プロセスが編集中ドラフトを消すことを防ぎます。
ドラフトは次回DB初期化時に破棄するため、未確定編集の復元機能はありません。

## 配信コメントからの更新

`教育(単語=読み)` は「配信コメント」グループを必要に応じて作成し、
そのグループ内の同じ単語を置き換えます。
`忘却(単語)` は同グループ内の一致行を削除します。他グループの登録は削除しません。
削除後に他グループの同じ単語が再び有効になる場合があります。

単語と読みの空文字は登録できません。
更新は設定画面のドラフトとは独立して確定し、設定画面のキャンセルでは取り消しません。
コマンドの書式と実行順は[読み上げ](speech.md)を参照してください。

## インポート

JSON・CSV・TXTを読み込めます。インポートもドラフトへの操作であり、OKで保存します。
読み込み失敗時は、そのインポートの変更をロールバックします。
JSONのグループ指定がない形式とCSV・TXTは、選択中グループへ追加します。
辞書全体をPythonへ渡さず、Rustで入力を順次処理します。

### JSON

UTF-8のJSONを読みます。次の3形式に対応します。

単語から読みへのオブジェクト:

```json
{"LiveVoiceBridge": "ライブボイスブリッジ"}
```

行オブジェクトの配列:

```json
[
  {"word": "LiveVoiceBridge", "reading": "ライブボイスブリッジ", "pos": "名詞", "comment": "製品名"}
]
```

グループ名から行配列へのオブジェクト:

```json
{
  "製品名": [
    {"word": "LiveVoiceBridge", "reading": "ライブボイスブリッジ"}
  ]
}
```

品詞キーは `pos` または `part_of_speech` を受け付けます。
グループ配列が空でもグループを作ります。
既存の `dictionary.json` はこのインポート操作で明示的に取り込みます。自動移行はしません。

### CSV・TXT

列の順番は「読み、単語、品詞、コメント」です。
CSVはヘッダーなしのカンマ区切り、TXTはタブ区切りです。
TXTでは空行と `!`・`#` から始まる行を無視し、単語列がない行も読み飛ばします。

```text
ライブボイスブリッジ,LiveVoiceBridge,名詞,製品名
```

CSV・TXTはBOM付きUTF-16 LE/BE、UTF-8、Shift-JISの読み込みに対応します。
これは既存辞書の入力対応です。プロジェクトの文書・設定・ソースの編集はUTF-8を使用します。
